# krea2-studio

Text2image и **edit по референсам** для Krea 2 на чистом `diffusers` + Gradio.

Стоковый `Krea2Pipeline` умеет только `text2image`. Edit-режим — сборка последовательности
с референсными токенами, ось кадра в RoPE, grounded encode и дозирование внимания —
реализован здесь.

Механика восстановлена по исходникам `diffusers` и community-ноды для ComfyUI,
а затем проверена на игрушечной модели: сборка последовательности, ось кадра в RoPE,
срез выхода и формулы буста прогонялись ассертами до переноса на реальные веса.

## Как это работает

```
последовательность:  [ текст | реф 1 | реф 2 | цель ]
позиции (t,h,w):     (0,0,0)  (1,h,w) (2,h,w) (0,h,w)
выход:               только целевые токены, срез с конца
```

Референсы — чистые (незашумлённые) VAE-латенты, упакованные так же, как цель, и
помеченные ненулевым номером кадра. Влияют исключительно через self-attention: если
замаскировать их столбцы, результат бит в бит совпадает с чистым t2i.

Второй канал — **grounded encode**: изображение уходит в Qwen3-VL вместе с инструкцией,
как это было в обучении. VAE-токены несут внешность, grounded — семантику сцены.

## Установка

```bash
pip install -r requirements.txt
```

Репозитории `krea/Krea-2-*` на Hugging Face **gated**: примите условия на странице модели
и положите токен в окружение, иначе загрузка упадёт с 401.

```bash
export HF_TOKEN=hf_...
python app.py
```

Переменные окружения:

| переменная | по умолчанию | зачем |
|---|---|---|
| `KREA2_MODEL` | `krea/Krea-2-Turbo` | `krea/Krea-2-Raw` для базового чекпоинта |
| `KREA2_PROCESSOR` | `Qwen/Qwen3-VL-4B-Instruct` | процессор для grounded encode |
| `KREA2_OFFLOAD` | `0` | `1` включает CPU-offload при нехватке VRAM |
| `HF_TOKEN` | — | доступ к gated-репозиториям |

## Настройки под чекпоинт

| | Turbo (TDM) | Raw (base) |
|---|---|---|
| шагов | 8 | 28 |
| guidance | **0.0** | 4.5 |

`guidance_scale` у Krea 2 сдвинут: velocity считается как `cond + scale·(cond − uncond)`,
поэтому `4.5` эквивалентно классическому CFG `5.5`, а `0.0` означает «CFG выключен».
Включённый CFG **удваивает** стоимость шага — на Turbo он не нужен.

## Цена edit-режима

Каждый референс добавляет столько же токенов, сколько занимает сама картинка:

| сценарий | длина последовательности | attention ~L² |
|---|---:|---:|
| t2i 496×864 | 2 186 | 1.00× |
| edit 496×864, 1 реф | 3 860 | 3.12× |
| edit 1024×1024, 1 реф | 8 704 | 15.85× |

`ref_boost ≠ 1.0` добавляет плотную матрицу `L×L` (28 МБ на 496×864, 390 МБ на 1328×1328)
и отключает FlashAttention. По умолчанию выключен.

## Структура

```
krea2_studio/
  geometry.py    подгонка референса: crop→resize в пикселях, снап /16, дробное центрирование
  grounding.py   шаблон Qwen3-VL с vision-токенами, динамический prefix_len
  attention.py   ref_boost как additive bias log(b), подмена процессоров внимания
  edit.py        Krea2EditPipeline: сборка последовательности, position_ids, денойз-луп
app.py           Gradio: две вкладки
```

## Развёртывание на GPU-инстансе

```bash
export HF_TOKEN=hf_...
bash bootstrap.sh
```

Скрипт ставит зависимости, качает веса в кэш на большом диске и прогоняет диагностику.
Веса тянутся **до** запуска UI — иначе первый запрос в Gradio висит без объяснений.

Отдельно диагностика:

```bash
python smoke_test.py --steps 4
```

Она идёт от простого к сложному — окружение, загрузка, t2i, edit без grounding,
проверка что референс вообще влияет, grounded encode, буст, геометрия — и на каждом
шаге печатает, что делать при провале. Результаты складываются в `smoke_out/`.

Шаг 5 заодно отвечает на открытый вопрос из раздела ниже: он печатает длину условия
(~350 токенов — vision-токены в условии, ~13 — отброшены).

## Статус проверки

Проверено исполнением: геометрия, нормализация латентов, формулы буста, сборка
последовательности и срез выхода — на игрушечной модели в ноутбуках 03 и 05.

**Не проверено на реальных весах** (нужен GPU): загрузка и прогон end-to-end, подмена
процессоров внимания для `ref_boost`, и главное — открытый вопрос, остаются ли
vision-токены в условии grounded encode или отбрасываются. Обе гипотезы различаются
длиной условия радикально (351 против 13 токенов), так что развести их легко.
